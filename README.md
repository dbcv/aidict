# aidict

カタカナの読みからローカルLLM（Ollama）で構造化された日本語辞書エントリを生成・蓄積・比較できる Web アプリケーションです。

## 主な機能
- **キャッシュ検索 & 追記生成**: SQLite（`aidict.db`）に保存済みの語は即座に表示。再生成時は上書きせず新しいエントリとして追加されるため、異なるモデルの出力を比較できます。
- **複数エントリの切り替え & 投票**: 同一見出しに複数エントリがある場合、左右ボタン・キーボード（`←` / `→`）・モバイルのスワイプで切り替え可能。`👍` / `👎` で投票できます。
- **Ollama エンドポイント & モデル切り替え**: 画面上部から接続先 URL と使用モデルを切り替えられます。
- **手動編集 & 削除**: 各エントリの表記・分類・品詞・意味・例文・補足を画面から直接編集・削除できます。
- **既存データ自動移行**: 初回起動時に `data.json` が存在する場合、自動で SQLite にインポートします。

## 起動方法
```bash
uv run python main.py
```
ブラウザで `http://localhost:5000/` を開いてください。

## 環境変数（任意 / `.env`）
- `OLLAMA_HOST`: デフォルトの Ollama エンドポイント（既定: `http://localhost:11434`）
- `OLLAMA_MODEL`: デフォルトのモデル名（既定: `nemotron3:33b`）
- `AIDICT_DB_PATH`: SQLite DB ファイルパス（既定: `aidict.db`）
- `PORT`: サーバーポート（既定: `5000`）
